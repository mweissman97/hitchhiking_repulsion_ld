# hitchhiking_repulsion_ld
Code for the manuscript "The counteracting effects of hitchhiking and repulsion of deleterious alleles during a selective sweep"

## simulations/
Simulations were written using [SLiM 5](https://messerlab.org/slim/). Simulations were run on [hoffman2](https://www.hoffman2.idre.ucla.edu/About/System-overview.html), a Linux compute cluster.

## sim_processing/
Python and R files used to process simulation outputs.

## sim_outputs/
Sample csv files generated by simulations that can be used to create all figures in manuscript.

## c_diff/
Data and post processing files for running iLDS and plotting LD decay for *Clostridium difficile*.
* c_diff.txt: Haplotype file for *Clostridium difficile* genomes from the Unified Human Gastrointenstinal Genome (UHGG) project (alias MGYG-HGUT-02369)

## make_figures/
R scripts used to generate all figures for paper.
